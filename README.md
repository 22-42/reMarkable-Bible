paper tablets. Hats off to [Asivery](https://github.com/asivery) for his XOVI framework including Appload 🔥
This is a students project ment to solidifying my C++ knowledge. Additionally Im trying to figure out good practice on coding with AI without sacrificing my ability to think or the projects code quality, readability, clarity and structure.
