# reMarkable-Bible

Custom [AppLoad](https://github.com/asivery/rm-appload) applications for reMarkable
tablets (XOVI extension on the rMPP).

## Contents

- `examples/appload-cpp-full/` — complete example AppLoad app with a **QML frontend and
  a C++ backend** (port of the Rust backend client `backends/appload-clients/rust-backend`
  from `asivery/rm-appload`), including build scripts for the PC emulator, rM1/rM2
  (armv7) and rMPP (aarch64). See
  [examples/appload-cpp-full/README.md](examples/appload-cpp-full/README.md).
